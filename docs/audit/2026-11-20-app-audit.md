# App audit — 20 Nov 2026

Scope: the free trace tool (`/copy`), the app landing (`/app`, `/app/course`), the homepage, all API routes, auth,
PWA and build. Method: code review of every route and of `ARTraceTool.tsx`, type check, lint, production build, and
the app run in the browser at 375 × 812 and 320 × 568. The browser pane blocks the camera, so camera behaviour on
real phones is from code review only and still needs a real-device check.

**Build health:** type check passes, production build passes, lint has 0 errors (≈80 warnings, mostly `<img>` and
hook dependencies). Note: `node_modules` was missing; it is now installed from `package-lock.json`.

Legend: ✅ confirmed in the browser · 🔍 found in code review

## P0 — fix before sending anyone to the app

### Safety (money, data, secrets)
1. 🔍 **`.env` is not ignored by git.** One `git add .` would publish the Mongo, Google, NextAuth, Gemini, Wavespeed,
   MiniMax and Cloudinary secrets. It has never been committed. Fix: add `.env` to `.gitignore`.
2. 🔍 **Anyone can give themselves credits.** `api/restore-credits` adds any amount to any email, with no sign-in.
3. 🔍 **Anyone can spend your paid AI accounts.** `generate-image-gemini`, `generate-image-wavespeed`,
   `video-generation`, `video-generation-wavespeedai` have no sign-in or credit check on the server; credits are
   only checked in the browser. A script could drain Gemini, Wavespeed, MiniMax and Cloudinary.
   The tool also gives a credit back when deducting fails, even for "insufficient credits".
4. 🔍 **Personal data readable by anyone:** `check-user` (whole user record), `user-mural-items?email=` (incl. IP
   addresses), `upload-mongodb` GET (every wall item's email, IP, browser), `video-generation/user`.
5. 🔍 **Anyone can overwrite the public mural** (`upload-mongodb` with any item id) and upload any video URL into your
   Cloudinary. `video-generation` fetches any URL it is given.
6. 🔍 **Debug routes are public:** `test-env`, `test-cloudinary`, `verify-cloudinary`. The unsigned
   `video-generation/callback` lets anyone mark jobs as done. `submit-form` returns error stack traces.

### Things users will hit
7. ✅ **Every page is blank until GrowthBook answers.** `GrowthBookProvider` renders nothing until feature flags load
   from cdn.growthbook.io, so the server-rendered page is empty; on a slow phone network it stays white for seconds,
   and if the request fails (ad blocker, network) it stays white for good. `enableDevMode: true` is on in production.
8. ✅ **The 5-day face course shows nothing.** The lesson SVGs have no width/height, so the browser reports size 0;
   the overlay box is placed off-screen and the picture is invisible (`/copy?course=face&day=2`).
9. 🔍 **Course mode undoes Lock.** Tapping Lock changes the toolbar height, which reloads the lesson: it unlocks,
   re-centres, resets opacity/strobe, and replaces any photo the user uploaded.
10. 🔍 **iPhones without a dual-wide camera get a 2× zoomed view.** Zoom 2 is forced on every iPhone; it is only "1×"
    on Dual Wide/Triple cameras (SE, XR, XS, many iPads get a cropped view).
11. 🔍 **Non-English phones can open the selfie camera.** Camera choice relies on English words in the camera label.
12. 🔍 **Camera can stay on after leaving.** Coming back from the photo picker starts the camera twice; the losing
    stream is never stopped. It also stops a recording in progress while the UI still shows REC.
13. ✅ **First screen gives no guidance.** `/copy` opens to a black screen with two small icons (Upload, Record). If
    the camera is denied there is a one-off `alert()` and then a black screen with no retry and no help.

## P1 — fix as part of the free-tool polish

14. 🔍 Moving/resizing writes inline styles that fight React state: a second photo with a different shape comes in
    stretched and off-centre; pinch snaps back to the old size; corner resize drifts from the finger.
15. 🔍 Leaving `/copy` while recording: the timer keeps running and a "Video saved!" download pops up on the next page.
16. 🔍 Saving video on iPhone: blob URL revoked after 1 s, goes to Files not Photos, alert mentions a "new tab" that
    never opens. Long recordings are held fully in memory and can crash the iOS tab. The overlay isn't recorded.
17. 🔍 Toolbar sits under the iPhone home indicator (no safe-area padding).
18. 🔍 Strobe, REC-dot and spinner animations probably never run (scoped `@keyframes` renamed by styled-jsx).
19. 🔍 Layers freezes the phone for seconds with no spinner (work runs before the drawer opens).
20. 🔍 Stale sketch: after an AI image or a lesson, Layers still uses the previous photo's sketch.
21. 🔍 HEIC photos on Android pass the type check and then fail to load.
22. 🔍 Camera that ends in the background is never restarted (black video when you come back).
23. 🔍 **A-Frame + AR.js load on every page** (~1 MB). AR.js comes from cdn.rawgit.com, shut down in 2019, so
    `/ar-tracking` can't work anyway.
24. 🔍 Icons: the PNG favicon/apple-touch-icon links point to files that don't exist (only SVGs, which iOS ignores),
    with relative paths that break on nested routes. The manifest has no 192 px icon, so Chrome won't offer install;
    `start_url` is `/` (the portfolio), not the tool.
25. 🔍 PWA caching rules use RegExps like `^\/api` that Workbox never matches (it tests the full URL), so offline
    caching of the tool doesn't happen; fixing them naïvely would cache personal API responses for 24 h.
26. 🔍 MongoDB: a new client per request; `check-credits`, `check-user`, `create-user`, `restore-credits`, `waitlist`
    never close it (connection exhaustion); other routes share and close a client mid-request.
27. 🔍 Routes throw at import time when an env var is missing, which breaks builds without the full `.env` (preview
    deploys, CI).
28. 🔍 New Google users who sign in from `/copy` never get a user record, so AI credits stay at 0.
29. 🔍 `user-scalable=no` blocks zoom (accessibility); `/copy` uses the portfolio's page title.
30. 🔍 `upload` and `upload-cloudinary` write to the local disk, which fails on Vercel.

## Fix status (20 Nov, same day)

Done (type check, lint and production build pass; checked in the browser at 375 × 812):
- **#1** `.env` is now in `.gitignore`.
- **#2–#3** Credits are spent and refunded on the server only (`src/lib/credits.ts`): spending a credit returns a
  one-time id; the four paid AI routes require sign-in plus that id, and a refund only works once, for your own
  unfinished spend. Tested: every paid/credit route returns 401 when signed out.
- **#4–#5** `check-user` answers only for the signed-in user with name/credits/level; `user-mural-items` and
  `video-generation/user` need sign-in (own items only); the public wall no longer sends emails, IPs or browser
  details; adding to the wall needs sign-in and can only update your own item; video routes only accept image data
  or your own Cloudinary images.
- **#6** Debug routes, the unsigned callback and the disk-writing upload routes are deleted; `submit-form` no longer
  returns stack traces.
- **#7** Pages render immediately; flags load in the background (3 s timeout). Dev mode only in development.
- **#8** The course SVGs contained an invalid control character (so no browser could show them) and had no size —
  both fixed; lessons now appear centred. **#9** Lock no longer reloads the lesson.
- **#10–#12** iPhone zoom 2 only on Dual Wide/Triple cameras; translated camera names no longer risk the selfie
  camera; camera starts are numbered so a stale start can't leave the camera on; no restart during recording; the
  camera restarts if the phone stopped it in the background.
- **#13 (part)** Camera problems show a clear help card (blocked / busy / no camera / needs https / unsupported)
  with phone-specific steps and Try again, instead of a pop-up and a black screen.
- **#14** New pictures always come in centred at the right shape. **#15** Leaving mid-recording no longer triggers
  a download or leaves a timer running. **#18** Animations fixed. **#26** One shared MongoDB connection.
- AI generation and the account button are hidden in the free tool (`NEXT_PUBLIC_ENABLE_AI=true` brings them back).
- `/copy` renders in the browser only and has its own page title; its first download fell from ~300 KB to ~105 KB.

New findings while fixing:
- **GrowthBook key is a secret admin key** exposed to browsers via `NEXT_PUBLIC_GROWTHBOOK_CLIENT_KEY`, and rejected
  by GrowthBook (so flags never loaded). The app now ignores any key that isn't an `sdk-` client key, but the value
  is still in builds until the env var changes. **Revoke it in GrowthBook** and set an SDK client key.
- **The MongoDB cluster in `.env` doesn't exist** (its address doesn't resolve on public DNS), so every database
  feature fails locally. Check which `MONGODB_URI` Vercel uses.
- `src/types/next-auth.d.ts` replaced next-auth's types instead of extending them (removed), and the old
  `@types/next-auth` v3 package was removed.
